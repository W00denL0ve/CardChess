# 地图制作指南

> 最后更新：2026-06-16 | 作者：WoodenLove

## 一、概述

> 本文档面向**关卡策划/美术**，提供从 Tilemap 绘制到运行时关卡数据生成的操作指南。通过本指南，您将能够创建关卡编辑场景、绘制地形、配置回合行动和胜利条件，并一键提取为运行时资产。

## 二、前置条件

- 已安装 Unity 2022.3.30f1c1 并打开项目
- 熟悉 Tile Palette 基本操作
- 已准备所需的地形 Tile 资产（`TerrainTile`）

## 三、操作步骤

### 1. Tilemap 层命名约定

场景中所有 Tilemap 层的名称决定提取器如何解析。以下是各层的命名约定（名称不区分大小写）：

| Tilemap 层名 | 必须 | 用途 |
|---|---|---|
| `Base` 或 `Layer0` | ✅ | 基础地形，定义网格尺寸 |
| `PlayerSpawn` 或 `PlayerStart` | ✅ | 玩家出生点标记 |
| `Goal` 或 `VictoryPoint` | ❌ | 目标点标记 |
| `WinCondition` 或 `VictoryCondition` | ❌ | 胜利条件配置 |
| `RoundX`（如 `Round1`、`Round2`） | ❌ | 第 X 回合的预设行动 |

场景层级结构建议：

```
├── Grid（GridManager）
│   ├── Base Tilemap         ← 基础地形
│   ├── PlayerSpawn Tilemap  ← 出生点
│   ├── Goal Tilemap         ← 目标点
│   ├── WinCondition Tilemap ← 胜利条件
│   ├── Round1 Tilemap       ← 第1回合行动
│   ├── Round2 Tilemap       ← 第2回合行动
│   └── ...
├── Units（运行时动态生成）
├── UI（Canvas）
└── Managers（GridManager、LevelManager、TurnManager 等）
```

### 2. 地形绘制

创建地形 Tile 资产：右键 → `Create` → `Tiles` → `TerrainTile`，设置地形类型和高度。

| 字段 | 说明 |
|---|---|
| `Terrain Type` | 地形类型（`ground`=可行走, `unreachable`=不可行走） |
| `Height` | 高度值（0=平地） |
| `Preview Sprite` | 编辑器预览用的精灵 |

选中 `Base` Tilemap 层 → 打开 Tile Palette（Window → 2D → Tile Palette）→ 用刷子工具绘制。

> **注意**：`Base` 层决定网格边界，提取前请确保已覆盖完整区域。

### 3. 玩家出生点

1. 右键 → `Create` → `Tiles` → `PlayerSpawnTile`，设置预览 Sprite。
2. 选中 `PlayerSpawn` Tilemap 层，标记出生点位置。
3. 多个出生点时玩家单位随机分配，数量应 ≥ 玩家阵容数量。

### 4. 胜利条件配置

在 `WinCondition` Tilemap 层上放置条件 Tile。规则：

- **同一 y 坐标** = AND 组合
- **不同 y 坐标** = OR 组合
- **相同 Tile 的数量** = 数值参数

可用条件 Tile：

| Tile 类型 | 数量含义 | 说明 |
|----------|---------|------|
| `KillAllEnemiesTile` | 忽略（标记） | 全歼所有敌方单位 |
| `SurviveRoundsTile` | 数量 = 回合数 | 坚守指定回合 |
| `ProtectUnitTile` | 忽略 | 保护指定单位（`targetUnitId` 需手动编辑） |
| `ReachGoalTile` | 忽略（标记） | 任意单位到达 Goal 位置 |

配置示例：通关条件 = 到达目标点 **OR**（全歼敌人 **AND** 存活 5 回合）

```text
y=2: [ReachGoal]                    → OR: ReachGoal
y=1: [KillAllEnemies]               → AND:
y=0: [Survive][Survive][Survive]
     [Survive][Survive]             → SurviveRounds(5)
```

### 5. 回合行动配置

在 `RoundX`（如 `Round1`）Tilemap 层上放置行动 Tile：

| Tile 类型 | 对应行动 | 说明 |
|-----------|---------|------|
| `SpawnUnitTile` | `SpawnUnitAction` | 在格子生成单位 |
| `CellChangeTile` | `CellChangeAction` | 改变格子地形 |
| `EffectApplyTile` | `EffectApplyAction` | 在格子应用效果 |

每个 `RoundX` Tilemap 对应一个回合，X 为回合编号，执行顺序为 Tile 遍历顺序。

### 6. 提取关卡数据

1. 保存场景。
2. 点击菜单 `Tools → Extract LevelData From Scene`。
3. 自动生成资产到 `Assets/ScriptableObjects/LevelData/`：

```text
Assets/ScriptableObjects/LevelData/
├── [SceneName].asset              ← 主 LevelData
├── GridData/
│   └── [SceneName]_Grid.asset     ← LevelGridData
└── TurnData/
    └── [SceneName]_Turns.asset    ← LevelTurnData
```

4. 检查生成的资产引用是否正确。
5. 将关卡场景和 `LevelData` 配置为 Addressable。

## 四、配置参考

### 关卡资产字段

| LevelData 字段 | 来源 | 说明 |
|---------------|------|------|
| `Grid Data` | 自动 | 引用生成的 LevelGridData |
| `Turn Data` | 自动 | 引用生成的 LevelTurnData |
| `Player Spawn Positions` | 自动 | 从 PlayerSpawn Tilemap 提取 |
| `Goal Positions` | 自动 | 从 Goal Tilemap 提取 |
| `Root Condition` | 自动/手动 | 胜利条件根节点 |

### SpawnUnitTile 参数

| 字段 | 说明 |
|------|------|
| `Spawn Group` | 随机生成池（可选） |
| `Fallback Unit Config` | 兜底单位配置 |
| `Faction Override` | 阵营覆盖 |
| `Count` | 生成数量 |
| `Search Range` | 出生点被占用时的搜索半径 |

### CellChangeTile 参数

| 字段 | 说明 |
|------|------|
| `Target Terrain` | 目标地形类型 |
| `Set Height` | 是否修改高度 |
| `New Height` | 新的高度值 |
| `Set Walkable` | 是否修改可行走属性 |

## 五、常见问题

**问题：提取后运行时格子异常**
**解决：** 检查 Base Tilemap 是否覆盖完整区域、层命名是否符合约定、Tile 是否使用 `TerrainTile`、提取后资产引用是否正确。

**问题：胜利条件不触发**
**解决：** 检查 `LevelData.rootCondition` 是否为空、WinCondition 层 Tile 绘制是否正确、`ProtectUnitTile.targetUnitId` 是否手动填写。

### Q: 胜利条件没有触发

- 确认 `VictoryChecker` 在场景中
- 确认 `LevelManager.Initialize` 时输出了 `VictoryChecker` 初始化日志
- 检查 `LevelData.rootCondition` 是否有值
- 需要单位死亡的场景：确认 `KillAllEnemiesCondition` 是否匹配正确的 `Faction`

### Q: 回合行动没有执行

- 确认 `LevelTurnData` 中有对应回合的 `RoundActions`
- 确认 `SpawnUnitAction` 的 `fallbackUnitConfig` 有值
- 确认 `Round` Tilemap 的名称格式正确（如 `Round1`）

### Q: 提取后 `ReachGoalCondition` 不生效

- 确认 `Goal` Tilemap 层存在并放置了 `GoalTile`
- 提取后检查 `LevelData.goalPositions` 是否有坐标数据
