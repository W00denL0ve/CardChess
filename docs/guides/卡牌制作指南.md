# 卡牌制作指南

> 最后更新：2026-06-16 | 作者：WoodenLove

## 一、概述

> 本文档面向**游戏策划**，提供卡牌从创建到测试的完整制作流程。通过本指南，您将能够创建 CardData、配置效果链（选择器/条件/效果），并注册到牌库。

## 二、前置条件

- 已了解效果链基本概念（SelectorStep → ConditionStep → EffectStep）
- 已准备好卡牌 Sprite/Artwork 资源

## 三、操作步骤

### 1. 创建 CardData

1. 在 Project 窗口右键 → `Create` → `CardChess/Cards/CardData`
2. 命名，例如 `Fireball.asset`
3. 选中该 asset，在 Inspector 中编辑

### 2. 配置卡牌基础信息

### 基础字段

| 字段 | 说明 | 示例 |
|------|------|------|
| `Card Name` | 卡牌名称 | `火球术` |
| `Artwork` | 卡面 Sprite | 拖入 |
| `Description` | 卡牌描述 | `造成 12 点火焰伤害` |
| `Destination` | 打出后去向 | `Discard` / `Destroy` / `ReturnToHand` |
| `Cost` | 能量消耗 | 2 |
| `Retain` | 回合结束是否保留在手牌 | false |

### 颜色配置

| 字段 | 说明 |
|------|------|
| `颜色预设` | 选 Red/Green/Blue 自动填充颜色 |
| `自定义颜色` | 手动调色，选 None 预设时使用此值 |

颜色会自动应用到卡牌预制体的三个 Image（`frontBackground`、`front`、`imageBackground`）。

### 3. 效果链概念

效果链是一条**顺序执行的步骤序列**，每条 CardData 可以有**多条效果链**（全部执行）。

### 步骤类型

| 类型 | 作用 | 数量 |
|------|------|------|
| **选择器** (SelectorStep) | 选择目标单位/格子 | 每条链 0~1 个 |
| **条件** (ConditionStep) | 判断是否继续执行 | 每条链 0~N 个 |
| **效果** (EffectStep) | 实际执行动作 | 每条链 1~N 个 |

### 执行流程

```
链开始
  → 选择器: 选取目标 (如最近敌人)
  → 条件: 目标是否存活?
    ├─ 是 → 执行效果 (造成伤害)
    └─ 否 → 中断整条链
  → 链结束
```

> 可选的 Condition 和 Selector 步骤，建议让选择器在最前，条件在中，效果在最后。

---

### 4. 创建选择器 (Selector)

### 内置选择器

所有选择器在 `Create → CardChess/EffectChain/Selectors/` 下创建。

| 选择器 | 说明 | 适用场景 |
|--------|------|----------|
| `Unit` | 选取一个友方/敌方单位 | 攻击、治疗 |
| `UnitAny` | 任意单位（不区分敌我） | 范围伤害 |
| `UnitBySource` | 选取执行者自身的单位 | 自身 buff |
| `UnitAnyBySource` | 选取执行者（用于 CardTarget） | **默认使用** |
| `CellPath` | 选取移动路径上的格子 | 移动效果 |
| `CellArea` | 选取范围内的格子区域 | 范围效果 |

### 最常用：UnitAnyBySource

对于卡牌效果（初始 executor = CardTarget），使用 `UnitAnyBySource` 选择器：

1. 右键 → `Create` → `CardChess/EffectChain/Selectors/UnitAnyBySource`
2. 命名例如 `SelectTarget.asset`
3. Inspector 设置：

| 字段 | 说明 | 常用值 |
|------|------|--------|
| `Target Faction` | 目标阵营 | `Enemy` |
| `Range` | 选择范围（格数） | 10（全图） |
| `Must Be Alive` | 是否只选活的 | ✅ |

> **注意**：如果 `Target Faction = Enemy`，选择器会列出场上所有敌方单位，有多个时让玩家选择，只有一个时自动确认。

---

### 5. 创建条件 (Condition)

### 内置条件

| 条件 | 路径 | 说明 |
|------|------|------|
| `ExecutedIsDead` | `CardChess/EffectChain/Conditions/ExecutedIsDead` | 目标是否已死亡 |

### 使用场景

在伤害效果前加一个 `ExecutedIsDead` 条件，如果目标在第一步选择后死亡，则跳过后续伤害，避免无效操作。

### 添加到效果链

在 ChainStep 列表中，`ConditionStep` 的 `Condition` 字段拖入条件 asset。

---

### 6. 创建效果 (Effect)

### 内置效果

所有效果在 `Create → CardChess/EffectChain/Effects/` 下创建。

| 效果 | 路径 | 说明 |
|------|------|------|
| `Damage` | `Effects/Damage` | 造成伤害 |
| `Move` | `Effects/Move` | 位移 |
| `Swap` | `Effects/Swap` | 交换位置 |
| `AddBuff` | `Effects/AddBuff` | 添加 Buff |
| `GiveMovePoint` | `Effects/GiveMovePoint` | 增加移动力 |

### DamageEffect 详解

这是最常用的效果。创建后配置：

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `Add Damage` | float | 0 | 基础伤害值（加算到攻击者 Attack） |
| `Multiply Damage` | float | 1 | 伤害倍率 |
| `Final Add Damage` | float | 0 | 最终加算（乘算后） |
| `Final Multiply Damage` | float | 1 | 最终乘算 |
| `Damage Type` | enum | Physical | 物理 / 魔法 |

#### 伤害公式

```
addSum = 攻击者.Attack + AddDamage + buff.AddSum
mulSum = MultiplyDamage × buff.MulSum
finalAddSum = FinalAddDamage + buff.FinalAddSum
finalMulSum = FinalMultiplyDamage × buff.FinalMulSum

伤害 = (addSum × mulSum + finalAddSum) × finalMulSum
最终 = max(1, round(伤害) - 目标防御)
```

#### 常见配置示例

| 效果 | addDamage | multiplyDamage | finalAddDamage | 说明 |
|------|-----------|---------------|---------------|------|
| 普通攻击 | 0 | 1 | 0 | 完全依赖攻击者 Attack |
| 火球术 | 10 | 1 | 0 | 固定 10 + 攻击者 Attack |
| 双倍打击 | 0 | 2 | 0 | Attack × 2 |
| 背刺 | 5 | 1.5 | 3 | (Attack + 5) × 1.5 + 3 |

### 7. 组合效果链

### 在 CardData 中添加效果链

1. 在 CardData Inspector 中找到 `Chains` 列表
2. 点击 `+` 添加一条新的 EffectChain
3. 展开新链，在 `Steps` 列表中点击 `+`

### 添加步骤

**点击 `Add Step` 右侧的小三角**，选择步骤类型：

| 选择 | 生成的类型 | 说明 |
|------|-----------|------|
| `SelectorStep` | 选择器步骤 | 需要拖入 Selector asset |
| `ConditionStep` | 条件步骤 | 需要拖入 Condition asset |
| `EffectStep` | 效果步骤 | 需要拖入 Effect asset |

### 典型卡牌效果链示例

#### 示例 1：火球术（单体伤害）

```
Chain 0:
  [0] SelectorStep → UnitAnyBySource (目标=敌方)
  [1] EffectStep   → DamageEffect (addDamage=10)
```

#### 示例 2：火球术（含条件检查）

```
Chain 0:
  [0] SelectorStep → UnitAnyBySource (目标=敌方)
  [1] ConditionStep → ExecutedIsDead (跳过已死目标)
  [2] EffectStep   → DamageEffect (addDamage=10)
```

#### 示例 3：连击（两条链）

```
Chain 0:
  [0] SelectorStep → UnitAnyBySource
  [1] EffectStep   → DamageEffect (addDamage=5)

Chain 1:
  [0] SelectorStep → UnitAnyBySource
  [1] EffectStep   → DamageEffect (addDamage=3)
```

> 多条链依次执行，每条链独立选择目标。

---

### 8. 注册到牌库

### 测试时

在场景中的 `TestCardFlow` 组件的 `Test Cards` 列表中拖入 CardData。

### 正式流程

1. 在 `RunState.deckCardIds` 中记录 CardData 的 Addressable 地址
2. 关卡初始化时通过 Addressables 加载到 `DeckManager.deck`

---

### 9. 测试卡牌

### 快速测试

1. 确保场景中有 `DeckManager`、`HandUI`、`TurnManager`、`AsyncEffectExecutor`、`ResourceManager`
2. 在 `TestCardFlow` 的 `Test Cards` 列表中加入卡牌
3. 运行游戏，按空格（或等待自动触发）
4. 抽牌后点击卡牌打出

### 验证要点

| 检查项 | 预期行为 |
|--------|----------|
| 能量消耗 | 能量够 → 打出；不够 → 拦截 |
| 费用颜色 | 能量够变白（发光）、不够变红 |
| 飞行动画 | 手牌 → 屏幕中央 → pending 区 |
| 选择目标 | 单个目标自动确认，多个等待点击 |
| 造成伤害 | 血条更新、数值正确 |
| 去向 | 弃牌/销毁/回手牌 |

## 五、常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 卡牌卡在 pending | 效果链未完成 | 检查 Console 日志，确认链执行到哪步 |
| 选择器无反应 | 没有符合条件的目标 | 检查阵营/范围/存活条件 |
| 伤害为 1 | 攻击力 ≤ 防御 | 检查攻击者 Attack 属性 |
| 动画不播放 | Animator Trigger 名称不匹配 | 检查 UnitAppearance 的 Trigger 名称 |
| 击打不扣血 | 缺少 AnimationEvent | 在攻击动画中添加 OnHitFrame Event |
