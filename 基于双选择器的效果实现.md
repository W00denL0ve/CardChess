优先考虑可扩展性，那么采用**双选择器设计**是明智的选择。下面将完整描述从接口定义到运行时调用的所有具体操作。

## 一、整体架构预览

```text
┌─────────────────────────────────────────────────────────────┐
│                         EffectContext                        │
│  - caster: GameObject                                        │
│  - anchor1: ITarget                                          │
│  - anchor2: ITarget                                          │
│  - customParams: object[]                                    │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼

│  Effect (ScriptableObject)                                   │
│  - selectorA: TargetSelector                                 │
│  - selectorB: TargetSelector                                 │
│  - combination: TargetCombination                            │

                              │
              ┌───────────────┼───────────────┐
              ▼               ▼               ▼
       DamageEffect     MoveEffect      SwapEffect
```

## 二、基础接口和类定义

### 2.1 ITarget 接口

所有可以被效果作用的对象都要实现这个接口。

```csharp
// 可作用目标接口
public interface ITarget
{
    // 获取该目标当前的世界坐标（如果适用）
    Vector3? GetWorldPosition();
    // 获取该目标所在的格子坐标（如果适用）
    Vector2Int? GetCellPosition();
    // 获取目标的 GameObject（用于显示、特效等）
    GameObject gameObject { get; }
}
```

**实现示例：单位目标**

```csharp
public class UnitTarget : ITarget
{
    public Unit unit;

    public UnitTarget(Unit u) => unit = u;

    public Vector3? GetWorldPosition() => unit?.transform.position;
    public Vector2Int? GetCellPosition() => unit?.currentCell;
    public GameObject gameObject => unit?.gameObject;
}
```

**实现示例：格子目标**

```csharp
public class CellTarget : ITarget
{
    public Vector2Int coord;

    public CellTarget(Vector2Int c) => coord = c;

    public Vector3? GetWorldPosition() => GridManager.GetWorldPosition(coord);
    public Vector2Int? GetCellPosition() => coord;
    public GameObject gameObject => null; // 格子可能没有独立GameObject
}
```

**实现示例：卡牌目标**（如果需要）

```csharp
public class CardTarget : ITarget
{
    public Card card;
    public CardTarget(Card c) => card = c;
    public Vector3? GetWorldPosition() => null;
    public Vector2Int? GetCellPosition() => null;
    public GameObject gameObject => null;
}
```

### 2.2 EffectContext 结构

```csharp
public struct EffectContext
{
    public GameObject caster;          // 施法者GameObject（通常挂有Unit组件）
    public ITarget anchor1;            // 第一个锚点（例如用户选中的单位）
    public ITarget anchor2;            // 第二个锚点（例如用户选中的格子）
    public object[] customParams;      // 额外动态参数
}
```

### 2.3 TargetSelector 基类

选择器负责从 `EffectContext` 中计算出一组目标。

```csharp
public abstract class TargetSelector : ScriptableObject
{
    // 核心方法：根据上下文返回目标列表
    public abstract List<ITarget> GetTargets(EffectContext context);
}
```

**常用选择器示例**（后续可不断扩展）：

```csharp
// 直接返回 anchor1（必须是ITarget）
[CreateAssetMenu(menuName = "Game/TargetSelector/Anchor1")]
public class Anchor1Selector : TargetSelector
{
    public override List<ITarget> GetTargets(EffectContext context)
    {
        return context.anchor1 == null ? new List<ITarget>() : new List<ITarget> { context.anchor1 };
    }
}

// 返回 anchor2
[CreateAssetMenu(menuName = "Game/TargetSelector/Anchor2")]
public class Anchor2Selector : TargetSelector { ... }

// 返回以 anchor1 为中心的半径内所有格子
[CreateAssetMenu(menuName = "Game/TargetSelector/CellsAroundAnchor1")]
public class CellsAroundAnchor1 : TargetSelector
{
    public int radius = 1;
    public override List<ITarget> GetTargets(EffectContext context)
    {
        var center = context.anchor1?.GetCellPosition();
        if (center == null) return new List<ITarget>();
        List<ITarget> cells = new List<ITarget>();
        for (int dx = -radius; dx <= radius; dx++)
            for (int dy = -radius; dy <= radius; dy++)
                cells.Add(new CellTarget(new Vector2Int(center.Value.x + dx, center.Value.y + dy)));
        return cells;
    }
}

// 返回所有敌人（忽略锚点）
[CreateAssetMenu(menuName = "Game/TargetSelector/AllEnemies")]
public class AllEnemiesSelector : TargetSelector
{
    public override List<ITarget> GetTargets(EffectContext context)
    {
        var casterUnit = context.caster?.GetComponent<Unit>();
        if (casterUnit == null) return new List<ITarget>();
        var enemies = CombatManager.GetEnemiesOf(casterUnit);
        return enemies.Select(e => new UnitTarget(e)).Cast<ITarget>().ToList();
    }
}
```

### 2.4 目标组合模式枚举

```csharp
public enum TargetCombination
{
    CrossProduct,      // 笛卡尔积：对每个a∈A,每个b∈B 执行一次
    Zip,               // 一一对应：A[i] 与 B[i] 配对（要求数量相等）
    FirstOfA_AllB,     // 只取A的第一个元素，与所有B配对
    AllA_FirstOfB,     // 所有A与B的第一个元素配对
}
```

### 2.5 Effect 基类

```csharp
public abstract class Effect : ScriptableObject
{
    [Header("目标选择")]
    public TargetSelector selectorA;        // 选择"执行者"或"源"
    public TargetSelector selectorB;        // 选择"承受者"或"目标"
    public TargetCombination combination = TargetCombination.CrossProduct;

    [Header("效果基本信息")]
    public string effectName;
    public Sprite icon;

    // 外部调用入口
    public void Apply(EffectContext context)
    {
        List<ITarget> targetsA = selectorA?.GetTargets(context) ?? new List<ITarget>();
        List<ITarget> targetsB = selectorB?.GetTargets(context) ?? new List<ITarget>();

        if (targetsA.Count == 0 || targetsB.Count == 0) return;

        switch (combination)
        {
            case TargetCombination.CrossProduct:
                foreach (var a in targetsA)
                    foreach (var b in targetsB)
                        ApplyToPair(a, b, context);
                break;

            case TargetCombination.Zip:
                int count = Mathf.Min(targetsA.Count, targetsB.Count);
                for (int i = 0; i < count; i++)
                    ApplyToPair(targetsA[i], targetsB[i], context);
                break;

            case TargetCombination.FirstOfA_AllB:
                var firstA = targetsA[0];
                foreach (var b in targetsB)
                    ApplyToPair(firstA, b, context);
                break;

            case TargetCombination.AllA_FirstOfB:
                var firstB = targetsB[0];
                foreach (var a in targetsA)
                    ApplyToPair(a, firstB, context);
                break;
        }
    }

    // 子类实现：对一对目标执行具体效果
    protected abstract void ApplyToPair(ITarget source, ITarget target, EffectContext context);
}
```

## 三、具体效果实现示例

### 3.1 移动效果（MoveEffect）

将源单位移动到目标格子。

```csharp
[CreateAssetMenu(menuName = "Game/Effect/Move")]
public class MoveEffect : Effect
{
    public bool requirePath = true;   // 是否需要路径可达

    protected override void ApplyToPair(ITarget source, ITarget target, EffectContext context)
    {
        // 源必须是单位，目标必须是格子
        UnitTarget unitTarget = source as UnitTarget;
        CellTarget cellTarget = target as CellTarget;
        if (unitTarget == null || cellTarget == null) return;

        Unit unit = unitTarget.unit;
        Vector2Int targetCell = cellTarget.coord;

        if (requirePath && !Pathfinding.HasPath(unit.currentCell, targetCell, unit.moveRange))
            return;

        // 执行移动（实际项目中可能启动协程或动画）
        MovementSystem.MoveToCell(unit, targetCell);
    }
}
```

### 3.2 伤害效果（DamageEffect）

通常只需要一个目标（承受者），但为了双选择器兼容，可以忽略 source，只使用 target。

```csharp
[CreateAssetMenu(menuName = "Game/Effect/Damage")]
public class DamageEffect : Effect
{
    public int damageAmount;

    protected override void ApplyToPair(ITarget source, ITarget target, EffectContext context)
    {
        // 只关心 target 是否是单位
        UnitTarget unitTarget = target as UnitTarget;
        if (unitTarget == null) return;

        unitTarget.unit.TakeDamage(damageAmount);
    }
}
```

此时可以配置 `selectorA` 为任意（例如 `Anchor1Selector`），`selectorB` 为 `AllEnemiesSelector`。伤害效果会忽略 source，对每个 target 造成伤害。

### 3.3 交换位置效果（SwapEffect）

将源单位与目标单位交换位置。

```csharp
[CreateAssetMenu(menuName = "Game/Effect/Swap")]
public class SwapEffect : Effect
{
    protected override void ApplyToPair(ITarget source, ITarget target, EffectContext context)
    {
        UnitTarget unitA = source as UnitTarget;
        UnitTarget unitB = target as UnitTarget;
        if (unitA == null || unitB == null) return;

        Vector2Int posA = unitA.unit.currentCell;
        Vector2Int posB = unitB.unit.currentCell;

        MovementSystem.Teleport(unitA.unit, posB);
        MovementSystem.Teleport(unitB.unit, posA);
    }
}
```

### 3.4 拉拽效果（PullEffect）

将目标单位拉向源单位（或者源格子）。复用移动效果，但目标格子计算方式不同。为了演示双选择器，可以写一个专门的选择器 `AdjacentCellsToSource`，然后使用 `MoveEffect`。

例如：`selectorA` = `AllEnemiesSelector`（敌人），`selectorB` = `AdjacentCellsToSource`（施法者相邻格子），组合方式为 `CrossProduct`。然后效果使用 `MoveEffect`，这样每个敌人都会被移动到施法者相邻的某个格子（可能需要进一步选择具体格子）。但这样可能多个敌人抢一个格子。因此更合理的做法：使用 `Zip` 配合自定义选择器，或者写专门的 `PullEffect`。

## 四、创建资产和配置示例

### 4.1 创建选择器资产

在 Unity 项目中：

- 右键 → Create → Game → TargetSelector → Anchor1Selector
- 命名为 `Selector_Anchor1`
- 同样的方式创建 `Selector_AllEnemies`、`Selector_CellsAroundCaster` 等。

### 4.2 创建效果资产

- 右键 → Create → Game → Effect → Move
- 命名为 `Move_5Steps`
- 配置：
  - `Selector A`：选择 `Selector_Anchor1`（表示要移动的单位由锚点1提供）
  - `Selector B`：选择 `Selector_Anchor2`（表示目标格子由锚点2提供）
  - `Combination`：`CrossProduct`（通常只有一个单位和一个格子）

### 4.3 创建卡牌资产

- 右键 → Create → Game → Card
- 命名为 `Card_Charge`
- `Effects` 列表中添加 `Move_5Steps`

## 五、运行时调用流程

### 5.1 玩家打出卡牌

假设卡牌需要玩家选择：一个己方单位（锚点1）和一个目标格子（锚点2）。

```csharp
public class CardSystem : MonoBehaviour
{
    public void PlayCard(Card card, ITarget anchor1, ITarget anchor2)
    {
        var context = new EffectContext
        {
            caster = currentPlayerUnit.gameObject,
            anchor1 = anchor1,
            anchor2 = anchor2,
            customParams = null
        };

        foreach (var effect in card.effects)
        {
            effect.Apply(context);
        }
    }
}
```

### 5.2 如果卡牌不需要两个锚点

例如“对所有敌人造成5点伤害”：这张卡牌不需要玩家选择锚点。那么调用时：

```csharp
var context = new EffectContext
{
    caster = currentPlayerUnit.gameObject,
    anchor1 = null,
    anchor2 = null,
    customParams = null
};
card.effects[0].Apply(context);
```

效果资产中的 `selectorA` 可以是任意（但会被 `AllEnemiesSelector` 覆盖），`selectorB` 选择 `Anchor1Selector` 也无所谓，因为伤害效果忽略 source，只取 target。

## 六、扩展性说明

### 6.1 新增目标类型（例如“装备”）

1. 实现 `EquipmentTarget : ITarget`
2. 编写对应的选择器 `AllEquipmentsSelector`
3. 如果需要效果作用于装备，则编写 `ModifyEquipmentEffect` 或复用 `DamageEffect`（可能不适用）

### 6.2 新增选择逻辑（例如“血量最低的单位”）

1. 继承 `TargetSelector`，实现 `GetTargets` 筛选逻辑
2. 无需修改任何效果代码

### 6.3 新增效果类型（例如“沉默”）

1. 继承 `Effect`
2. 实现 `ApplyToPair`（通常只关心 target）
3. 在配置中搭配适当的选择器即可

### 6.4 需要三个或更多目标的情况

双选择器已经能处理大多数情况。如果确实需要三个目标（例如“单位A对单位B施加效果，同时影响单位C”），可以通过 `customParams` 传递第三个目标，或者将效果拆分为两个连续效果。

## 七、注意事项

1. **选择器的性能**：选择器每次都会重新计算目标列表。如果目标列表很大且每帧调用，需要考虑缓存，但在回合制游戏中通常不是问题。
2. **空目标处理**：如果 `selectorA` 或 `selectorB` 返回空列表，效果应静默失败，不报错。
3. **类型安全**：在 `ApplyToPair` 中，子类需要将 `ITarget` 向下转型为具体的类型（如 `UnitTarget`）。如果类型不匹配，应 `return` 并可选打印警告。
4. **UI交互**：选择器可能需要打开UI让玩家选择（例如 `SingleAllySelector`）。这通常需要访问 `UIManager`，可以在选择器内部通过 `Singleton` 或依赖注入实现。另一种方式是在卡牌系统中预先完成选择，将选好的目标作为 `anchor1` / `anchor2` 传入，选择器只需简单返回锚点。推荐后者，使选择器保持纯数据计算。
5. **序列化**：`ITarget` 是接口，不能直接序列化到 `EffectContext` 中（因为是运行时结构体），不需要保存。延迟效果存储 `PendingEffect` 时，需要将 `ITarget` 转换为可序列化的形式（例如存储 `Unit` 引用或格子坐标）。
