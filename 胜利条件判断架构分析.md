
## 胜利条件系统架构

### 核心思路

把"胜利条件"从关卡数据中抽离为**可组合的条件资产**，每个关卡引用一个条件列表，满足任意一个即胜利。

```
LevelData
  └─ victoryConditions: List<VictoryCondition>
  
VictoryCondition (ScriptableObject / 或 Serializable 类)
  ├─ KillAllEnemies
  ├─ SurviveRounds(n)
  ├─ ProtectUnit(unitId)
  ├─ BossKill(bossUnitId)
  ├─ ReachPosition(cell)
  └─ ...
```

### 架构图

```
┌─────────────────────────────────────────────────┐
│                  VictoryChecker                  │
│  (挂载在 LevelManager 或独立 GameObject)          │
│                                                  │
│  CheckWin() → bool                               │
│  遍历所有条件，任一满足 → 调用 OnVictory()         │
│  全部不满足且不可达成 → 调用 OnDefeat()            │
└──────────────────┬──────────────────────────────┘
                   │ 在哪些时机检查？
                   │
       ┌───────────┼─────────────┐
       ▼           ▼             ▼
  Unit死亡后   Enemy回合结束    Player回合结束
  (OnDeath)   (EndPhase)      (EndPhase)
```

### 条件接口

```csharp
public abstract class VictoryCondition : ScriptableObject
{
    [TextArea] public string description;    // 条件描述，UI 显示用

    /// <summary>当前是否满足胜利条件</summary>
    public abstract bool IsMet();

    /// <summary>是否已不可能满足（用于决定失败）</summary>
    public abstract bool IsImpossible();

    /// <summary>初始化（关卡开始时调用，绑定事件等）</summary>
    public virtual void Initialize() { }

    /// <summary>清理（关卡结束时调用）</summary>
    public virtual void Cleanup() { }
}
```

### 几个内置实现

**KillAllEnemies**：
```csharp
public class KillAllEnemiesCondition : VictoryCondition
{
    public override bool IsMet() =>
        LevelManager.Instance?.GetUnitsOf(Faction.Enemy).Count == 0;

    public override bool IsImpossible() =>
        LevelManager.Instance?.GetUnitsOf(Faction.Player).Count == 0;
}
```

**SurviveRounds**：
```csharp
public class SurviveRoundsCondition : VictoryCondition
{
    public int requiredRounds;
    private int _endPhaseCount;

    public override void Initialize()
    {
        _endPhaseCount = 0;
        GameEventChannel.Register<PhaseChangedEvent>(OnPhaseChanged);
    }

    private void OnPhaseChanged(PhaseChangedEvent evt)
    {
        if (evt.newPhase == TurnPhase.End) _endPhaseCount++;
    }

    public override bool IsMet() => _endPhaseCount >= requiredRounds;

    public override bool IsImpossible() =>
        LevelManager.Instance?.GetUnitsOf(Faction.Player).Count == 0;

    public override void Cleanup() =>
        GameEventChannel.Unregister<PhaseChangedEvent>(OnPhaseChanged);
}
```

**ProtectUnit**：
```csharp
public class ProtectUnitCondition : VictoryCondition
{
    public string targetUnitId;

    public override bool IsMet() =>
        LevelManager.Instance?.AllUnits.Any(u => u.UnitId == targetUnitId && u.IsAlive) == true;
    // 胜利条件是"保护"，所以只要目标活着就是胜利——这与上面的世界观矛盾
    // 实际上这个条件应该与 KillAllEnemies 组合使用：
    //   KillAllEnemies || ProtectUnitAlive
    // 但 ProtectUnit 作为失败条件更合理
}
```

### 调用时机

在 `VictoryChecker` 中：

```csharp
public class VictoryChecker : MonoBehaviour
{
    [SerializeField] private List<VictoryCondition> conditions;

    void OnEnable() => GameEventChannel.Register<UnitDeathEvent>(OnUnitDeath);
    void OnDisable() => GameEventChannel.Unregister<UnitDeathEvent>(OnUnitDeath);

    public void CheckWin()
    {
        bool anyMet = conditions.Any(c => c.IsMet());
        bool allImpossible = conditions.All(c => c.IsImpossible());

        if (anyMet) OnVictory();
        else if (allImpossible) OnDefeat();
    }

    private void OnUnitDeath(UnitDeathEvent evt) => CheckWin();

    private void OnVictory()
    {
        Logger.Log("[胜利] 条件达成！");
        // 转胜利结算
    }

    private void OnDefeat()
    {
        Logger.Log("[失败] 所有胜利条件均不可达成");
        // 转失败结算
    }
}
```

### LevelData 扩展

```csharp
public class LevelData : ScriptableObject
{
    public LevelGridData gridData;
    public LevelTurnData turnData;
    public List<Vector2Int> playerSpawnPositions = new();
    public List<VictoryCondition> victoryConditions = new();  // ← 新增
}
```

### 使用方法

1. 右键创建 `KillAllEnemiesCondition` 资产，拖入关卡 `LevelData`
2. 如果要"全歼敌人 + 保护指定单位"，直接加两个条件（OR 逻辑，任一满足即胜利）
3. 如果要"全歼敌人 AND 无人阵亡"，加一个自定义条件或组合条件

---

这套架构的核心优势：
- **新增条件只需新建一个 ScriptableObject 子类**，零侵入
- **条件可复用**，不同关卡引用同一份资产
- **OR 组合**天然支持（任一满足即胜利）
- **失败检测**通过 `IsImpossible()` 自动判断
- **与你现有系统无缝整合**——`UnitDeathEvent`、`PhaseChangedEvent` 都已就绪
